# Working agreements

Replace this with your project's: what it is, how to build and test it, and its conventions.

- Build: `npm run build` · Test: `npm test` · Lint: `npm run lint`
- Branches: `story/<JIRA-KEY>-<slug>`. Commits: `<JIRA-KEY>: <what changed>`.
- One story per branch and pull request. Keep unrelated refactoring out.
- Every acceptance criterion gets a test.
- Before opening a pull request, ask the `reviewer` agent to check the change.
