First public release: an agent harness for TypeScript and the `heaw` CLI.

- **Engine:** agent loop with streaming events, any AI SDK provider (OpenAI, Azure OpenAI, Anthropic, Google, Ollama, OpenAI-compatible; local models that cannot reason work too), a model catalog with prices, retries (also of responses cut off half way), turn, token, cost and time limits with a warning near each, and context compaction.
- **Tools:** files, commands (also in the background, such as a dev server), web pages, configured HTTP APIs, a task list, custom tools with `defineTool`, and any MCP server over stdio or HTTP, with OAuth logins and the MCP Registry.
- **Safety:** permission modes and allow / ask / deny rules (checked for each command of a chained command line), approvals, protected harness files the agent cannot change without asking, a Docker workspace that can push with a scoped token, `/rewind` for a run's file changes, and secret redaction in logs and traces.
- **Project layer:** `heaw.config.ts`, `AGENTS.md`, `.mcp.json`, hooks at eleven points (with the run's edited files and `runAgent` for reviews), agent definitions for sub-agents (run in parallel for independent plan steps with their own files and checks, sharing the run's budget, with their own model, reasoning effort and MCP servers or a cheaper default model, a reviewer that ends with a verdict, and a tester that uses a web app in a browser after interface changes), skills, and a memory of notes for later sessions; `heaw init` scaffolds it and sets up the project's tests as a check.
- **CLI:** interactive chat with approvals and slash commands (`/setup` has the agent configure the harness for the project with you, and the chat applies it; the agent plans bigger tasks in plan mode, asks you to approve the plan (or `/plan`) and builds all of it in one go, and a later conversation picks up a plan with open steps where it stopped; "yes for the session" covers all edits, or commands starting the same way), `heaw run` for scripts and CI, saved and resumable sessions, `heaw sessions`, `heaw mcp`, `heaw models` and `heaw eval`.
- **Quality:** the agent is told when it goes in circles (a call failing the same way three times, a file going back and forth) and thinks harder after a failed check; `/retro` has the agent review a session and turn what went wrong into lasting fixes (`AGENTS.md` lines, rules, hooks, skills, eval cases); an eval runner with fixtures or commits, command, file and model-judged checks, check files the agent never sees, turn budgets, each trial's steps in the report, regression cases from sessions (`heaw eval add`) and comparison of reports and of models; sessions linked to the commits and pull requests they produced; where tokens go (`/cost`); and OpenTelemetry traces following the GenAI semantic conventions.
- **Library:** `createEngine`, `createProjectEngine`, sessions, `runAgent` and `callTool` for workflows in code.
