'heaw': major

First public release: an agent harness for TypeScript and the `heaw` CLI.

- **Engine:** agent loop with streaming events, any AI SDK provider (OpenAI, Azure OpenAI, Anthropic, Google, Ollama, OpenAI-compatible; local models that cannot reason work too), a model catalog with the current models' prices and context windows, retries (also of responses cut off half way), turn, token, cost and time limits with a warning near each and a final answer at the turn limit, and context compaction that keeps what was ruled out and what was verified. A message typed while the agent works is queued and reaches it before its next step.
- **Tools:** files, commands (also in the background, such as a dev server, stopped when heaw ends or the next time it starts), web pages, configured HTTP APIs, a task list, custom tools with `defineTool`, and any MCP server over stdio or HTTP, with OAuth logins, the MCP Registry, reconnects after a server stops, and tools loaded on demand when a project has many. Tools can return images, such as a browser screenshot, to models that can see.
- **Safety:** permission modes and allow / ask / deny rules (checked for each command of a chained command line and for output redirected into files; deny and ask rules can carry a hint for the agent), approvals, protected harness files and project checks (lint, format and CI configs) the agent cannot change without asking, a trust step before loading a project whose config runs code, MCP tools pinned when first seen, commands without heaw's credentials or variables that look like secrets, `web_fetch` kept from cloud metadata and private addresses, paths checked by where links really lead, warnings for invisible characters in what the agent reads, a Docker workspace (the default for unattended runs in `bypass` mode) that can push with a scoped token, `/rewind` for a run's file changes, and secret redaction in logs and traces.
- **Project layer:** `heaw.config.ts`, `AGENTS.md`, `.mcp.json`, hooks at eleven points (with the run's edited files, `runAgent` for reviews, and Esc stopping them), agent definitions for sub-agents (run in parallel for independent plan steps with their own files and checks, sharing the run's budget, with their own model, reasoning effort, MCP servers and run limit, or a cheaper default model; a reviewer that ends with a verdict, and a tester that uses a web app in a browser after interface changes and looks at its pages wide and narrow), skills, and a memory of notes for later sessions; `heaw init` scaffolds it and sets up the project's tests as a check.
- **CLI:** interactive chat with approvals and slash commands (`/setup` has the agent configure the harness for the project with you in three rounds, and the chat applies it; the agent plans bigger tasks in plan mode, asks you to approve the plan (or `/plan`) and builds all of it in one go, and a later conversation picks up a plan with open steps where it stopped; "yes for the session" covers all edits, or commands starting the same way; the terminal bell rings when an approval waits), `heaw run` for scripts and CI, saved and resumable sessions, `heaw sessions`, `heaw mcp`, `heaw models` and `heaw eval`.
- **Quality:** the agent is told when it goes in circles (a call failing the same way three times, a file going back and forth) and thinks harder after a failed check; checks before finishing can send it back up to five times; it asks the user about decisions the request and project leave open; `/retro` has the agent review a session and turn what went wrong into lasting fixes (`AGENTS.md` lines, rules, hooks, skills, eval cases); an eval runner with fixtures or commits, command, file and model-judged checks, check files the agent never sees, follow-up messages, a simulated user who answers the agent's questions, guards switched off for comparison (`--without`), turn budgets, each trial's steps in the report, regression cases from sessions (`heaw eval add`) and comparison of reports and of models; sessions linked to the commits and pull requests they produced; where tokens go (`/cost`); and OpenTelemetry traces following the GenAI semantic conventions.
- **Library:** `createEngine`, `createProjectEngine`, sessions, `runAgent` and `callTool` for workflows in code.

If you ran heaw from source before this release:

- The package is now called `heaw`. Configs that import from `harness-engineered-agentic-workflow` still load.
- Pass `signal` to `workspace.exec` in your hooks, so Esc stops the tests too: `async beforeStop({ workspace, signal }) { await workspace.exec('npm test', { signal }) }`.
- Add `maxRuns: 2` to a reviewer written before. For a tester written before, run `/setup` again.
- An allow rule such as `run_command(npm test*)` no longer allows `npm test > file`; a command that needs a secret variable gets it through `workspace.passEnv`, e.g. `['GH_TOKEN']`; an unattended run in `bypass` mode uses the Docker workspace unless the config sets `workspace: { type: 'local' }`.
