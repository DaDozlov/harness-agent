# Contacts

A small address book page: `server.js` (Node, no dependencies) serves `public/` and the contacts.

- Start: `npm run dev` (http://localhost:4391)
- Test: `npm test`
- After a change to the page, have the `tester` agent use it in the browser (`delegate`, with what changed and what users should now see), and fix what it marks "fix first".
